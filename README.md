# WebOperator project page

Source of the WebOperator project page, served with GitHub Pages from this branch.
The code of WebOperator itself is on the `main` branch.

- `index.html`: the page (inline CSS and JavaScript, no build step)
- `method/index.html`: the `/method` route, which opens the walkthrough in full view
- `assets/`: images the page uses

Preview locally with `python -m http.server`, then open http://localhost:8000.
